# Kosmara

**La sencillez de un único universo.**

Interfaz DeFi sin custodia: pools de liquidez, swaps en 14 redes y swaps entre redes, con tu wallet (Phantom, MetaMask, Ledger…). Cada operación la firmas tú; Kosmara nunca toca tus fondos.

- Web: https://kosmarafi.github.io/
- Soporte: kosmara.soporte@gmail.com

## Estructura

- `index.html` — la aplicación completa (HTML, CSS y JS en un solo archivo)
- `i18n/` — traducciones (9 idiomas además del español)
- `icons/`, `logo/` — iconos de la app y logo en alta resolución
- `chains/`, `wallets/` — logos de redes y wallets
- `sdk/` — SDK de Orca empaquetado para el navegador
- `okx-proxy/` — Worker de Cloudflare para OKX DEX (opcional)
- `manifest.webmanifest`, `sw.js` — app instalable (PWA)
